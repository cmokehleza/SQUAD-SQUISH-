# Squad Squish!

A colorful Sillyville website and playable browser game starring Boing, Munch,
Zippy, Goofy, and Bloop.

## Play Giggle Gem Rescue

Open `index.html` and choose **Play Game**, or open `game.html` directly. The
game is fully contained in the static site and does not require a build step.

- Move with **WASD** or the **arrow keys**.
- Use a charged super move with **Space** or **E**.
- Pause with **P** or **Escape**.
- On phones and tablets, use the on-screen direction and super buttons.

Recover one Giggle Gem piece in each district: Boing Peak, Snacky Street, and
Chaos Castle. Every playable character has a different ability based on their
established Squad Squish personality and power.
